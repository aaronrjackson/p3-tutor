Context and memory in an agent

From Lesson 1. Source: Anthropic, Effective context engineering for AI agents.

Where does a piece of information live?

PlaceLastsUse for
ContextOne call; the program re-sends it each stepThe question, tool results, what the model needs right now
Saved notes (store outside the model)Across sessions, until deletedTraining status, preferences, bookings; must be saved and loaded
Searched documents (retrieval)Permanent; only chosen chunks enter the contextManuals and other large sources

Rules to remember

  • The model keeps nothing between calls; the program holds the history.
  • Context tokens are paid for at every call, so total cost grows with steps times context size.
  • More context is not free: context rot lowers recall as it grows.
  • Keep tool results small; clear old results; compact when needed (lossy).
  • Memory needs both a save step and a load step.
  • Retrieval: up front (program searches first) or just in time (model calls a search tool). Say "not found" rather than guess.
