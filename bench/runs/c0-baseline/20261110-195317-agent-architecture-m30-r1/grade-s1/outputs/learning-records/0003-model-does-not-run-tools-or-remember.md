# Open misconceptions: the model runs the tools (M4) and remembers on its own (M3)

On quiz 0001, submission s1, Riley believed the model opens the booking system and runs the three tools itself in one call (M4). Riley also believed the model remembers earlier sessions on its own (M3). Riley did show that the loop needs a stopping condition and that the model picks tools from their descriptions.
Context and memory lessons should start by correcting both: the program runs the tools, and the model only sees what the program puts in its input.
