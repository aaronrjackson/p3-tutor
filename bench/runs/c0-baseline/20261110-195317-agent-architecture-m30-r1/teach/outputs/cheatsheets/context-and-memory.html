Context and memory in an agent

From Lesson 1.

Terms

  • Context window: all the text the model can use for one call: system prompt, tool descriptions, conversation, and its answer. It has a token limit.
  • Token: a small chunk of text; you pay for tokens on every call.
  • Context rot: accuracy and recall fall as the window fills.
  • Compaction / clearing: summarize the run, or drop old tool results, to free the window.
  • External memory (notes): facts saved outside the window and reloaded later.
  • Retrieval: fetching a few relevant passages from a store, up front or just in time via a tool.

Where does it live?

NeedMechanismMakerspace example
Within one runThe window; the program re-sends it every callCalendar result used in the final answer

Long documentsRetrieval tool returning a few passagesBandsaw speed from the right manual page

Cost rule

Input tokens for call n = fixed part + question + every earlier request and result. Total = the sum over all calls. A large result that arrives early is paid for by every later call.
