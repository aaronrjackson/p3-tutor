Live data (calendar)Tool call, lean resultGoes stale; fetch when needed

Rules of thumb

  • The model keeps nothing between calls; the program re-sends the history.
  • Input cost: sum of every call's full context, so it grows faster than the step count.
  • Keep the context small: lean tools first, then trimming, then compaction.
  • Memory between sessions = notes your program saves and loads, not model learning.
  • Retrieval: split, index, search, add top chunks with their source.
