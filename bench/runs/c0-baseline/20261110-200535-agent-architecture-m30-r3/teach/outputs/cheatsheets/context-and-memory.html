Context and memory in an agent

From lesson 1.

Terms

  • Context: the tokens given to the model in one call.
  • Context window: the most tokens one call can hold, reply included.
  • Context rot: recall gets worse as the context grows.
  • Memory: storage kept by your program, read back into the window.
  • Retrieval: fetching only the needed part into the window.
  • Compaction: summarizing a full context and continuing in a fresh window.

Rules of thumb

  • The model keeps nothing between calls; the program resends.
  • Input tokens for a request = the sum of every call's whole context, so each result is paid for again on later calls.
  • Return small pieces from tools, never whole manuals.
  • Facts the system must get right come from your database, not from model-written notes.
