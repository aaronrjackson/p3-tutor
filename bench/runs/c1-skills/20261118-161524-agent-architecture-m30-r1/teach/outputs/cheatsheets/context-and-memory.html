Rules

  • The model keeps no state. The program re-sends the whole history every call.
  • Cost of a run = sum of the input of every call, not the final size.
  • Everything counts toward the window: prompt, tools, messages, tool results, output.
  • More context can lower recall (context rot). Keep the smallest useful set.
  • Shrink: short tool results, tool-result clearing, compaction (can lose facts).

Retrieval

  • Chunk, embed, search, add top chunks to the context.
  • Embeddings find meaning. BM25 (keywords) finds exact codes. Use both.
  • Put the machine name in each chunk.
  • Under about 200,000 tokens, consider skipping retrieval and testing it.
  • Retrieval does not teach the model. Search again each session.
