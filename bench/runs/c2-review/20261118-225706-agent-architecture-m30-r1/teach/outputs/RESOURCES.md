# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on the attention budget, context rot, just-in-time retrieval and note-taking. Use for: what to keep in context and what to load later.
- [Article: "Contextual Retrieval" (Anthropic)](https://anthropic.com/research/contextual-retrieval)
  Explains chunking, keyword plus embedding search, and measured retrieval failure rates. Use for: designing manual search.
- [Docs: Context windows (Claude documentation)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How the window is counted. Use for: token limits and cost reasoning.
- [Article: "Managing context" (Anthropic)](https://claude.com/blog/context-management)
  Clearing old tool results and the memory tool. Use for: long requests and memory between sessions.
