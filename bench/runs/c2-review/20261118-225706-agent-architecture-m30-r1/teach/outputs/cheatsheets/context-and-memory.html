Cheat sheet: where a fact lives in an agent

From Lesson 1. Three questions: Is it needed on every call? Is it long, and only a part is needed? Does it last beyond a session?

PlaceUse forCostRisk
Context (system prompt)Short rules, needed every callTokens on every callRot and cost if too long
Database + toolExact facts that last: training, bookingsTokens only when readStale data
RetrievalLong manuals; a few chunks per questionTokens for the chunksWrong or missed chunk
NotesLow-risk facts learned in chatTokens when loadedModel writes them wrongly

Rules

  • The model keeps nothing between calls. The program re-sends the history.
  • Cost of a request is the sum of every call's whole context.
  • Keep tool results short. Drop or summarize old ones.
  • If the answer is not in the context, the model cannot use it. Check what retrieval returned first.
